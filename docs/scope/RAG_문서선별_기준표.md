# RAG 문서선별 기준표

## 1. 문서 목적

본 문서는 공장 수호대 MVP에서 사용할 RAG 근거 문서를 선별하기 위한 기준표이다.

RAG 문서 선별의 목적은 단순히 안전문서를 많이 수집하는 것이 아니라, Vision AI가 감지한 위험 이벤트에 대해 작업자가 이해할 수 있는 근거 기반 답변을 생성할 수 있도록 공식 문서와 실무형 자료를 구분하는 것이다.

본 기준표는 `MVP 위험범위 정의서`에서 확정한 1차 구현 위험유형 3개와 선행 자료조사 대상 2개를 기준으로 작성한다.

## 2. RAG 문서 선별 기본 원칙

### 2.1 핵심 원칙

1. 공식성이 높은 문서를 우선한다.

2. MVP 위험유형과 직접 연결되는 문서를 우선한다.

3. 작업자에게 즉시 설명할 수 있는 조치사항이 있는 문서를 우선한다.

4. 출처, 문서명, 조항, 페이지 위치를 남길 수 있는 문서를 우선한다.

5. 근거가 불명확하거나 범위가 너무 넓은 문서는 RAG 1차 투입에서 제외한다.

### 2.2 RAG 답변 원칙

RAG 답변은 법률 자문이 아니라 안전문서 기반 안내로 제한한다.

답변에는 가능한 경우 문서명, 조항, 페이지, 문단 위치를 함께 표시한다.

근거 문서가 검색되지 않으면 추측해서 답변하지 않고, 관리자 확인 또는 관련 문서 미확인 상태로 안내한다.

## 3. 문서 등급 분류

| 등급 | 분류명 | 의미 | RAG 투입 여부 |
|---|---|---|---|
| A | 핵심 근거문서 | MVP 위험유형 3개와 직접 연결되는 공식 문서 | 1차 투입 |
| B | 보조 설명문서 | 작업자에게 쉬운 설명을 만들 때 도움이 되는 안전자료 | 보조 투입 |
| C | 확장 조사문서 | 지게차 근접, 안전조끼 등 향후 확장용 문서 | 별도 보관 |
| D | 참고 문서 | 배경 설명에는 유용하지만 직접 답변 근거로 약한 문서 | 보류 |
| E | 제외 문서 | 출처가 불명확하거나 MVP 범위 밖인 문서 | 제외 |

## 4. 문서 선별 점수 기준

문서 후보는 아래 기준으로 10점 만점 평가한다.

| 평가 항목 | 점수 | 판단 기준 |
|---|---:|---|
| MVP 위험유형 직접 연결성 | 3점 | 안전모, 안전화, 위험구역 진입 중 하나와 직접 연결되는가 |
| 공식 출처 여부 | 2점 | 법령, KOSHA, 고용노동부, 공공기관 자료인가 |
| 조치사항 명확성 | 2점 | 착용, 이탈, 작업중지, 관리자 확인 등 행동 지시가 가능한가 |
| 조항 또는 위치 표시 가능성 | 1점 | 조항, 장, 절, 페이지, 문단 위치를 기록할 수 있는가 |
| 작업자 설명 적합성 | 1점 | 전문 용어를 줄여 작업자용 문장으로 바꾸기 쉬운가 |
| 최신성 또는 현장 적용성 | 1점 | 현재 기준으로 활용 가능하거나 현장 적용성이 높은가 |

## 5. 점수별 처리 기준

| 총점 | 처리 결과 | 설명 |
|---:|---|---|
| 8점 이상 | 1차 RAG 투입 | MVP 답변의 핵심 근거로 사용한다 |
| 6점에서 7점 | 보조 RAG 투입 | 쉬운 설명, 예시, 작업자 안내 문구 생성에 사용한다 |
| 4점에서 5점 | 보류 | 직접 근거로 쓰기 어렵지만 배경자료로 보관한다 |
| 3점 이하 | 제외 | MVP와 관련성이 낮거나 근거 품질이 부족하다 |

## 6. 필수 통과 조건

다음 조건을 모두 만족하면 1차 RAG 투입 후보로 검토한다.

1. 공식 출처 또는 신뢰 가능한 기관 문서이다.

2. 최소 하나 이상의 MVP 위험유형과 연결된다.

3. 작업자가 해야 할 행동으로 변환할 수 있다.

4. 문서명과 위치 정보를 기록할 수 있다.

5. 과도한 해석 없이 답변 근거로 사용할 수 있다.

## 7. MVP 위험유형별 우선 문서

### 7.1 안전모 미착용

감지 이벤트명: `no_helmet`

검색 키워드: 안전모, 보호구, 머리 보호, 낙하물, 착용, 지급, 관리

| 우선순위 | 문서 유형 | 선별 대상 | RAG 활용 방식 |
|---|---|---|---|
| 1 | 법령 | 산업안전보건기준에 관한 규칙 중 보호구 지급, 착용, 관리 관련 조항 | 보호구 착용 필요성의 강한 근거 |
| 2 | KOSHA Guide | 개인보호구 지침 | 안전모 착용 이유와 관리 기준 설명 |
| 3 | OPS 또는 안전자료 | 안전모 착용, 낙하물 위험 관련 한 장 자료 | 작업자용 쉬운 설명 생성 |
| 4 | 사내 SOP | 현장별 안전모 착용 구역 기준 | 현장 맞춤 답변 보강 |

선별 판단 문장:

이 문서가 안전모를 왜 착용해야 하는지, 어떤 상황에서 착용해야 하는지, 미착용 시 어떤 위험이 있는지를 설명할 수 있으면 우선 선별한다.

### 7.2 안전화 미착용

감지 이벤트명: `no_safety_shoes`

검색 키워드: 안전화, 보호구, 발 보호, 낙하물, 찔림, 미끄러짐, 끼임

| 우선순위 | 문서 유형 | 선별 대상 | RAG 활용 방식 |
|---|---|---|---|
| 1 | 법령 | 산업안전보건기준에 관한 규칙 중 보호구 지급, 착용, 관리 관련 조항 | 안전화 착용 필요성의 기본 근거 |
| 2 | KOSHA Guide | 개인보호구 지침 | 안전화의 목적과 착용 기준 설명 |
| 3 | 안전보건자료 | 발 부상, 미끄러짐, 낙하물, 찔림 관련 자료 | 위험 상황별 쉬운 설명 생성 |
| 4 | 사내 SOP | 안전화 필수 착용 작업장 기준 | 현장별 착용 의무 안내 |

선별 판단 문장:

이 문서가 발 부상 위험, 중량물 낙하, 바닥 미끄러짐, 날카로운 물체 찔림, 끼임 위험 중 하나 이상을 설명할 수 있으면 우선 선별한다.

### 7.3 위험구역 진입

감지 이벤트명: `restricted_zone_entry`

검색 키워드: 위험구역, 출입금지, 출입통제, 위험성평가, 설비 접근, 작업중지, 관리자 확인

| 우선순위 | 문서 유형 | 선별 대상 | RAG 활용 방식 |
|---|---|---|---|
| 1 | 법령 | 산업안전보건법 중 위험성평가, 안전조치, 교육 관련 조항 | 위험구역 관리 필요성의 상위 근거 |
| 2 | KOSHA Guide | 작업장 출입통제, 위험구역, 설비 접근 관련 지침 | 구역 진입 경고의 실무 근거 |
| 3 | 안전작업허가 자료 | 위험 작업 전 허가 절차 자료 | 관리자 확인, 작업 전 승인 안내 |
| 4 | 사내 SOP | 출입 제한 구역, 설비 접근 금지 구역 기준 | 현장 맞춤 구역 안내 |

선별 판단 문장:

이 문서가 특정 구역에 왜 들어가면 안 되는지, 들어갔을 때 어떤 조치를 해야 하는지, 관리자 확인이 필요한지를 설명할 수 있으면 우선 선별한다.

## 8. 선행 자료조사 대상 문서

다음 문서는 1차 MVP 기능 구현 대상은 아니지만, 본선 확장성과 발표 설득력을 위해 별도 조사한다.

### 8.1 지게차와 작업자 근접

감지 이벤트명: `forklift_worker_proximity`

검색 키워드: 지게차, 차량계 하역운반기계, 충돌, 안전거리, 동선 분리, 신호수, 보행자 통로

| 우선순위 | 문서 유형 | 선별 대상 | 활용 방식 |
|---|---|---|---|
| 1 | KOSHA Guide | 지게차 작업 안전 지침 | 확장 기능 근거 |
| 2 | 법령 또는 규칙 | 차량계 하역운반기계 관련 안전 기준 | 충돌 예방 답변 근거 |
| 3 | 안전자료 | 작업자와 차량 동선 분리 자료 | 발표용 확장 시나리오 |
| 4 | 사내 SOP | 지게차 운행 구역, 보행자 통로 기준 | 현장 맞춤 확장 |

처리 기준:

기능 구현 대상이 아니므로 1차 RAG 투입에는 넣지 않는다. 다만 문서ID를 `EXT_FORKLIFT` 계열로 부여하여 확장 조사 폴더에 보관한다.

### 8.2 안전조끼 미착용

감지 이벤트명: `no_safety_vest`

검색 키워드: 안전조끼, 반사조끼, 고시인성 보호구, 차량 이동 구역, 시인성, 충돌 예방

| 우선순위 | 문서 유형 | 선별 대상 | 활용 방식 |
|---|---|---|---|
| 1 | KOSHA Guide | 개인보호구 지침 | 보호구 확장 근거 |
| 2 | 안전자료 | 고시인성 보호구, 반사조끼 관련 자료 | 작업자 시인성 설명 |
| 3 | 차량 안전 자료 | 차량 이동 구역 작업자 보호 자료 | 지게차 근접 확장과 연결 |
| 4 | 사내 SOP | 차량 구역 안전조끼 착용 기준 | 현장 맞춤 확장 |

처리 기준:

안전조끼는 안전모, 안전화와 같은 PPE 계열이지만 1차 MVP 구현 대상이 아니므로 확장 조사 문서로 분류한다.

## 9. 제외 문서 기준

다음 문서는 RAG 1차 투입에서 제외한다.

| 제외 기준 | 이유 |
|---|---|
| 출처가 불명확한 블로그, 카페, 개인 글 | 공식 근거로 사용하기 어렵다 |
| 법령 전체 원문 전체 삽입 | 검색 범위가 너무 넓어 부정확한 답변 위험이 있다 |
| MVP와 직접 관련 없는 고소작업, 화재, 밀폐공간 자료 | 현재 기능 범위를 벗어난다 |
| 오래된 자료인데 최신 여부 확인이 어려운 문서 | 안전 기준이 바뀌었을 가능성이 있다 |
| 제품 홍보성 자료 | 객관적 안전 근거로 쓰기 어렵다 |
| 이미지 중심이라 텍스트 추출이 어려운 문서 | RAG 검색 품질이 떨어질 수 있다 |

## 13. RAG 답변 품질 기준

RAG에 투입된 문서는 다음 답변을 만들 수 있어야 한다.

### 13.1 기본 답변 구조

1. 감지된 위험 상황 설명

2. 왜 위험한지 설명

3. 지금 해야 할 조치 안내

4. 근거 문서명 또는 조항 표시

5. 추가 확인이 필요한 경우 관리자 확인 안내

### 13.2 예시 구조

위험유형: 안전모 미착용

답변 방향: 현재 작업자가 안전모를 착용하지 않은 상태로 감지되었습니다. 낙하물이나 충돌로 인한 머리 부상 위험이 있으므로 즉시 안전모를 착용하고 작업을 계속해야 합니다. 관련 근거는 보호구 지급과 착용 기준을 다루는 문서에서 확인할 수 있습니다.

위험유형: 안전화 미착용

답변 방향: 현재 작업자가 안전화를 착용하지 않은 상태로 감지되었습니다. 중량물 낙하, 날카로운 물체 찔림, 미끄러짐으로 인한 발 부상 위험이 있으므로 안전화를 착용한 뒤 작업해야 합니다.

위험유형: 위험구역 진입

답변 방향: 현재 작업자가 출입 제한 구역에 진입한 것으로 감지되었습니다. 설비 작동, 충돌, 끼임 위험이 있을 수 있으므로 즉시 구역 밖으로 이동하고 관리자에게 확인해야 합니다.

## 15. 최종 판단 기준

본 MVP의 RAG 1차 문서셋은 안전모 미착용, 안전화 미착용, 위험구역 진입에 직접 연결되는 문서만 포함한다.

지게차와 작업자 근접, 안전조끼 미착용 문서는 기능 구현 대상이 아니라 확장 조사 대상으로 별도 관리한다.

최종 RAG 투입 문서는 작업자가 위험 경고를 받았을 때 왜 위험한지, 지금 무엇을 해야 하는지, 어떤 근거 문서가 있는지를 설명할 수 있어야 한다.
